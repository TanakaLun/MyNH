# MyNH

## MyNHentai, 一款以UI/UX设计为主要开发方向的同时实现较为符合人类操作偏好的现代 Nhentai 客户端
本项目使用 [miuix](https://github.com/compose-miuix-ui/miuix/) 作为设计主题。意愿上本项目使用 jetpack compose + kotlin 作为前后端的实现，在提供优美视觉效果的同时保证了良好的兼容性与优雅的性能表现。
## 关于前景
本项目不一定会勤于更新或实现在当前基础之上的更多特性、功能和拓展。

你可以在 issues 许愿，但本项目没有实现它们的义务。

当然，本项目非常赞同有意愿者通过 fork 本仓库来继续开发，倘若有下游向本仓库发起 pull request 则亦然如此。
